# Drawing Assistant
> 참고자료를 단순히 보는 것을 넘어, 그림을 이해하고 분석하며 그리는 과정을 돕는 드로잉 학습 보조 프로그램

## 1. 프로젝트 소개 (About)

**Drawing Assistant**는 그림을 독학하거나 드로잉 실력을 향상시키려는 사람들을 위한 Python 기반 드로잉 학습 보조 프로그램입니다.

기존 크로키 및 드로잉 참고자료 플랫폼은 주로 포즈 제공, 자료 검색, 카테고리 분류 및 타이머 기능에 집중되어 있습니다.

하지만 그림을 연습하는 과정에서는 단순히 참고자료를 보는 것뿐만 아니라, 인체의 구조와 비율, 광원의 방향, 명암, 반사광, 의상의 주름 등 그림을 구성하는 다양한 요소를 이해하는 과정 또한 중요합니다.

본 프로젝트는 이러한 점에 주목하여 기존의 크로키 연습 기능에 더해, **참고 이미지를 여러 시각적 요소로 분해하고 분석할 수 있는 기능**을 제공하는 것을 목표로 합니다.

## 2. 개발 목적 (Motivation)

그림을 처음 시작하거나 독학하는 사람들은 참고자료를 보더라도 다음과 같은 어려움을 겪습니다.

- 인체의 구조와 신체 비율을 파악하기 어려움
- 특정 포즈에서 인체가 어떤 형태로 구성되는지 이해하기 어려움
- 광원의 위치와 빛이 닿는 방향을 판단하기 어려움
- 반사광과 그림자의 차이를 이해하기 어려움
- 옷주름이 발생하는 원인과 흐름을 파악하기 어려움
- 참고자료를 관찰하는 것과 실제 그림으로 표현하는 것 사이에 어려움이 있음

이러한 문제를 해결하기 위해 참고 이미지를 단순한 이미지가 아닌 분석 가능한 학습 자료로 활용할 수 있는 환경을 구축하고자 합니다.

## 3. 주요 기능 (Features)

### 3.1. 크로키 및 참고자료 관리
- 다양한 인체 및 포즈 참고자료 제공
- 포즈와 신체 방향에 따른 자료 분류
- 특정 자세 및 앵글 검색
- 크로키 연습용 타이머
- 사용자 참고 이미지 등록 및 관리

### 3.2. 이미지 분석 및 분해
참고 이미지를 여러 요소로 구분하여 시각적으로 확인할 수 있도록 지원합니다.

- **인체 도형화:** 인체를 구, 원기둥, 박스 등의 기본 도형으로 표현
- **광원 분석:** 광원의 위치와 방향을 표시
- **명암 분석:** 빛과 그림자의 영역을 구분
- **반사광 분석:** 주변 환경에 의해 발생하는 반사광의 이해 보조
- **의상 주름 분석:** 옷주름의 방향과 흐름을 시각화

### 3.3. 레이어 기반 분석 시스템
하나의 참고 이미지를 여러 분석 요소로 분리하여 확인할 수 있도록 구성합니다.

- 분석 요소별 개별 표시 및 숨기기
- 원본 이미지와 분석 결과 비교
- 여러 분석 레이어 동시 표시
- 분석 요소별 독립적인 확인 및 조작

## 6. 향후 개발 방향 (Future Plans)

궁극적으로는 하나의 일러스트를 다양한 시각적 요소로 분해하여 사용자가 그림의 구조와 원리를 이해할 수 있도록 하는 것이 목표입니다.

단순히 완성된 그림을 모방하는 데 그치지 않고, 그림을 구성하는 요소를 직접 관찰하고 분석하면서 자신만의 그림을 그릴 수 있도록 돕는 프로그램으로 발전시키고자 합니다.

## 7. 프로젝트 목표 (Goal)

**See → Analyze → Understand → Draw**

참고자료를 보는 것에서 시작해 분석하고 이해한 뒤, 스스로 그릴 수 있도록 돕는 것이 본 프로젝트의 최종 목표입니다.
